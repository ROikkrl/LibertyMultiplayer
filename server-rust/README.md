# LibertyMultiplayer — сервер для Ubuntu 22.04

Сервер на Rust поддерживает до четырёх игроков. Формат обмена привязан к версии сервера. Для 0.2.11-test используйте Windows-лаунчер 0.2.11-test. При несовпадении версий сервер сообщает свою версию и блокирует вход и успешный пинг.

## Запуск

Распакуйте архив на сервере и выполните из папки `server-rust`:

```bash
bash start-server.sh
```

В архив включён статический бинарник Linux x86‑64. Первый запуск создаёт случайный ключ в `session.key`. Сервер работает в текущем терминале. Для остановки нажмите Ctrl+C. Параметры можно переопределить переменными `LF_BIND`, `LF_PORT` и `LF_KEY_FILE`. Если запускать из исходников без готового бинарника, установите Cargo. Скрипт сам соберёт release-версию.

## Подключение

Если UFW уже включён, разрешите входящий UDP:

```bash
sudo ufw allow 24840/udp
```

Если публичный IP у роутера, пробросьте UDP 24840 на локальный адрес Ubuntu. Проверьте, что сервер слушает порт, из второго терминала:

```bash
ss -lun | grep ':24840'
cat session.key
```

В лаунчере укажите публичный IPv4, порт 24840 и ключ из `session.key`. Из домашней сети можно указать локальный IPv4 Ubuntu. Передайте ключ другу приватно. Пакеты подписаны общим ключом HMAC-SHA256, координаты передаются без шифрования.

Кнопка «Проверить сервер» в лаунчере 0.2.1 проверяет ответ с тем же ключом, не занимая место игрока. При запуске через скрипт события записываются в терминал и в `server.log`. Просмотр в реальном времени: `tail -f server.log`. Путь можно изменить переменной `LF_LOG_FILE`.

С версии 0.2.9-test каждое новое подключение записывается с идентификатором игрока, его IP и числом занятых мест. При отключении через F9 сервер пишет `reason=client`. Если пакет отключения не дошёл, сервер удаляет игрока по тайм-ауту.

## Синхронизация окружения

Клиенты отправляют снимки окружения примерно 10 раз в секунду. Сервер принимает трафик от источника с наибольшим приоритетом в группе. Приоритет равен индексу мощности (0.01–0.99), умноженному на число полных секунд активной игры (до 3600). Для разных эпизодов источники выбираются независимо. Источник передаёт полный снимок несколькими частями. При подтверждении посадки сервер исключает исходную машину из трафика в том же обновлении, в котором принимает нового водителя.

Состояние машин хранится отдельно от снимков источника. Если источник уезжает или выходит, сервер может передать симуляцию машины другому клиенту рядом с ней, сохранив идентификатор. Клиент, которому передана машина, продолжает её симуляцию локально в GTA IV.
