# LibertyMultiplayer — прототип для GTA IV Complete Edition

До четырёх игроков обмениваются состоянием через UDP-сервер. В 0.2.4-test целевая частота обмена позами игроков и управляемых машин составляет около 30 Гц. Машины окружения считываются до 10 раз в секунду и сглаживаются на каждом игровом кадре. Рядом с одним участником сессии передаются позиции до двух прохожих и двух машин окружения. Это визуальные копии.

## Лаунчер Windows

Скачайте установщик Windows и архив сервера Ubuntu из [GitHub Releases](https://github.com/ROikkrl/LibertyMultiplayer/releases).

Закройте GTA IV и запустите скачанный установщик. Нажмите «Выбрать и установить» и укажите папку с `GTAIV.exe` или родительскую папку с подпапкой `GTAIV`. Чтобы обновить файлы по сохранённому или введённому вручную пути, нажмите «Патчить выбранную папку». Лаунчер установит клиент мода и зависимости для Complete Edition 1.2.0.59. При замене файлов он сохранит копии в папке `LibertyFriends-backup-*` внутри игры. Если в Windows отсутствует Visual C++ x86, его штатный установщик может запросить права администратора.

После установки введите адрес, UDP-порт и ключ сессии. Нажмите «Подключиться» и загрузите сохранение. Синхронизация запускается автоматически при готовой игре и активном лаунчере.

Лаунчер 0.2.4 сохраняет путь к игре, адрес, порт и ключ в профиле Windows. Смена версии EXE не сбрасывает параметры. Ключ защищён Windows DPAPI в контексте текущего пользователя.

Установите клиент 0.2.8-test на оба ПК. Rust-сервер 0.2.7-test совместим. Кнопка «Проверить сервер» проверяет UDP-соединение и ключ без GTA IV. После подключения проверьте, что друзья появляются на карте и рядом в игре. Аватары и транспорт запускаются автоматически. Аватары пока используют модель прохожего. Для ожидания, ходьбы, бега и спринта используются штатные циклы игрока GTA IV из move_player. Цикл выбирается по скорости аватара. Общее окружение включается автоматически. Сервер назначает источники по районам. У получателя позиции машин и прохожих воспроизводятся с буфером. Для посадки остановите машину рядом с другом и нажмите F10 на ПК пассажира. Повторное нажатие F10 просит персонажа выйти. После посадки мод запрашивает станцию водителя и проверяет, переключилась ли она. Состояние двигателя и сирены передаётся вместе с машиной. Позиция внутри трека выбирается локально. Запуск синхронизации, потери связи и отключения отмечаются в журнале с временем UTC. Всплывающих сообщений в игре нет. При вылете полезны `GTAIV/mods/LibertyFriends/client.log` и серверный `server.log`.

## Следующий этап сервера

Сервер Rust распределяет источники окружения по секторам 160 × 160 м и передаёт окружение от выбранного источника участникам этого сектора. Это работает в любой части карты, где есть игроки. Пустые районы не симулируются.

PvP и рагдоллы включаются автоматически вместе с остальной синхронизацией на Rust-сервере. Кулаки, оружие ближнего боя и поддерживаемое огнестрельное оружие используют зарегистрированные GTA IV попадания. Сервер проверяет дистанцию и обрабатывает контакты машин по сетевой траектории. Рагдолл показывает состояние падения и позицию. Положение отдельных костей рассчитывает локальная игра. Python-сервер поддерживает старый режим без PvP.

Серверу нужны постоянные идентификаторы сущностей, назначение владельца физики машины и подтверждение занятых мест. Владелец считает физику в GTA IV и передаёт позу и скорость. Сервер проверяет владельца, упорядочивает снимки и подтверждает события. Места, урон и удаление машины можно передавать отдельными подтверждаемыми сообщениями. Для трафика можно назначать один источник симуляции на район и передавать управление при его отключении. Полный перенос физики GTA IV и ИИ на Ubuntu потребует отдельной реализации симуляции.

Лаунчер проверяет последний стабильный релиз GitHub и открывает страницу Releases, если указан репозиторий. Для локальной сборки поместите рядом с EXE файл `release-repo.txt` с `владелец/репозиторий`.

## Ручная установка из исходников

1. Нужна Steam-сборка GTA IV `1.2.0.59` и Python 3.10 или новее.
2. Рядом с `GTAIV.exe` установите 32-битный [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) и [ScriptHookDotNet CE 1.7.2.0](https://www.nexusmods.com/gta4/mods/1217?tab=files).
3. Скопируйте `scripts/LibertyFriends.cs` в `GTAIV/scripts/`. Если используете собранный `LibertyFriends.net.dll`, положите туда только DLL. Скопируйте `mods/LibertyFriends` из проекта в `GTAIV/mods/`: эта папка служит для обмена данными с Python. Команды ниже выполняются из папки с `liberty_friends.py`.

## Закрытая сессия

Используйте одну локальную сеть или частную VPN. На хосте сгенерируйте ключ и передайте его участникам приватно.

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Хост запускает сервер. Замените `IP_ХОСТА` на адрес хоста в общей сети, а `КЛЮЧ` на полученное значение.

```powershell
python liberty_friends.py serve --bind IP_ХОСТА --key КЛЮЧ
```

Каждый участник, включая хост, запускает клиент. Укажите путь к своей установленной папке мода. Если Windows блокирует обмен, проверьте доступ к входящему UDP-порту `24840` на хосте в общей сети.

```powershell
python liberty_friends.py join --host IP_ХОСТА --key КЛЮЧ --mod-dir "C:\ПапкаИгры\GTAIV\mods\LibertyFriends"
```

Запустите основную GTA IV и загрузите свободную игру из сохранения. После подключения через лаунчер синхронизация начнётся, когда сможете управлять персонажем. Откройте карту после того, как оба игрока войдут в мир. Зелёная отметка должна двигаться вслед за другом и исчезнуть через несколько секунд после остановки его клиента. Если отметок нет, убедитесь, что рядом с `manifest.lua` обновляются файлы `position.txt` и `peers.txt`, и посмотрите журнал запуска в client.log.

Протокол проверяет подлинность пакетов общим ключом HMAC. Координаты передаются открытым текстом, поэтому для игры через интернет используйте частную VPN. Для проверки на одном ПК адрес сервера по умолчанию — `127.0.0.1`.
