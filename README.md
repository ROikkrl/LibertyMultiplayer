# LibertyMultiplayer — прототип для GTA IV Complete Edition

До четырёх игроков обмениваются состоянием через UDP-сервер. В 0.2.4-test целевая частота обмена позами игроков и управляемых машин составляет около 30 Гц. Машины окружения считываются до 10 раз в секунду и сглаживаются на каждом игровом кадре. Рядом с одним участником сессии передаются позиции до двух прохожих и двух машин окружения. Это визуальные копии.

## Лаунчер Windows

Скачайте установщик Windows и архив сервера Ubuntu из [GitHub Releases](https://github.com/ROikkrl/LibertyMultiplayer/releases).

Закройте GTA IV и запустите скачанный установщик. Нажмите «Выбрать и установить» и укажите папку с `GTAIV.exe` или родительскую папку с подпапкой `GTAIV`. Чтобы обновить файлы по сохранённому или введённому вручную пути, нажмите «Патчить выбранную папку». Лаунчер установит клиент мода и зависимости для Complete Edition 1.2.0.59. При замене файлов он сохранит копии в папке `LibertyFriends-backup-*` внутри игры. Если в Windows отсутствует Visual C++ x86, его штатный установщик может запросить права администратора.

После установки введите адрес, UDP-порт и ключ сессии. Нажмите «Подключиться» и загрузите сохранение. Синхронизация запускается автоматически при готовой игре и активном лаунчере.

Лаунчер 0.2.4 сохраняет путь к игре, адрес, порт и ключ в профиле Windows. Смена версии EXE не сбрасывает параметры. Ключ защищён Windows DPAPI в контексте текущего пользователя.

Установите клиент 0.2.13-test на оба ПК и Rust-сервер 0.2.13-test. Кнопка «Проверить сервер» проверяет UDP-соединение, ключ и версию без GTA IV. Несовпадение версий блокирует проверку и вход. После загрузки сохранения синхронизация начинается автоматически. При ответе сервера игра показывает `Connected to <IP>`. Клавиша F9 отключает игровую сессию или подключает повторно. Клавиша F возле общей машины запрашивает место водителя. F10 также позволяет сесть пассажиром к другу. События клиента записываются в `GTAIV/mods/LibertyFriends/client.log`, события сервера в `server.log`.

## Сеть и окружение

Клиент опрашивает сервер до 60 раз в секунду и отправляет свежие игровые кадры с движением игрока и сигналами его машины. Снимки окружения передаются примерно 10 раз в секунду. Для удалённых пеших игроков применяется буфер поз, передаётся тип движения и используется прогноз по горизонтали до 100 мс. Принципы независимой отправки движения и управления одной машиной при смене водителя использованы по примеру [IV:MP](https://github.com/Neproify/ivmultiplayer/blob/e9fadfc74a87f0d1d232f507b2e0bbdf22a1ab52/Client/Core/CRemotePlayer.cpp).

Rust-сервер назначает одну запущенную GTA IV источником окружения для игроков рядом друг с другом. Группа может пересекать границы прежних секторов. Источник снимает состояние до 10 машин и 17 пешеходов, а сервер проверяет снимок, хранит его с ограниченным сроком жизни и выдаёт каждому игроку только машины и NPC поблизости. Загрузка и выгрузка объектов, трафик, ИИ и физика выполняются оригинальным движком на источнике. При уходе источника сервер назначает другой экземпляр игры. В районах без игроков живой симуляции нет.

Приоритет хоста равен индексу мощности, умноженному на число полных секунд игры после загрузки сохранения, максимум 3600 секунд. Учитывается время текущего запуска GTA IV, включая игру до подключения. Меню и пауза время не добавляют. При равном приоритете выше игрок, подключившийся раньше. Индекс от 0.01 до 0.99 сохраняется в лаунчере. Его исходное значение оценивается по количеству логических процессоров.

Хост эпизода определяется по максимальному приоритету. Когда игроки разъезжаются, сервер поручает симуляцию каждого занятого района GTA IV, которая его прогрузила. Машина сохраняет сетевой идентификатор при передаче симуляции. Пока рядом есть игрок, сервер хранит последнее состояние до 20 секунд в ожидании нового источника.

После полного снимка от источника остальные клиенты убирают локальный трафик и прохожих небольшими порциями. Сетевые копии, сюжетные сущности, поезда, текущая и последняя машина игрока сохраняются. Очистка приостанавливается во время миссий, при смене источника и при потере связи.

Машины передают позу с наклоном, цвета, фары, стоп-сигналы, гудки, поворотники, сирену, состояние двигателя, здоровье и проколотые шины. Для Steam-сборки 1.2.0.59 мод считывает угол поворота колёс, педаль тормоза, таймер гудка и таймер сигнализации. Левый и правый поворотники можно включать клавишами `[` и `]`, оба вместе клавишей `\`. Если игра сообщает о мигании без направления, передаются оба борта. При посадке по F10 мод меняет станцию у пассажира и проверяет переключение. Позиция внутри композиции остаётся локальной. Для NPC передаются модель, поза, тип движения и состояние рагдолла, а для машин трафика также модель водителя.

Сетевые машины участвуют в локальных столкновениях. Скорость, высота и наклон кузова применяются с коррекцией движения, а вращение колёс и ход подвески рассчитывает местный движок GTA IV. Сервер оставляет машины трафика в снимках при кратких пропусках данных, подтверждает смену водителя и продолжает передавать последнюю машину игрока после выхода, пока она загружена рядом с этим игроком.

PvP и рагдоллы включаются автоматически вместе с остальной синхронизацией на Rust-сервере. Кулаки, оружие ближнего боя и поддерживаемое огнестрельное оружие используют зарегистрированные GTA IV попадания. Сервер проверяет дистанцию и обрабатывает контакты машин по сетевой траектории. Наезд передаётся пострадавшему и наблюдателям как событие с направлением удара. Положение отдельных костей рассчитывает локальная игра. Python-сервер поддерживает старый режим без PvP и расширенных снимков.

Лаунчер проверяет последний стабильный релиз GitHub и открывает страницу Releases, если указан репозиторий. Для локальной сборки поместите рядом с EXE файл `release-repo.txt` с `владелец/репозиторий`.

## Локальный патч Vladivostok FM

Поместите `LibertyMultiplayer-Radio.zip` рядом с актуальным лаунчером, не распаковывая архив. При запуске лаунчер включит опцию «Установить патч Vladivostok FM». Укажите папку игры и установите мод. Радиопатч использует каталог `update` и при необходимости устанавливает FusionFix из локального архива. При замене существующих файлов лаунчер сохраняет их резервные копии.

Для самостоятельной сборки распакуйте `Resources/Radio Restorer/data1.dat` из [Radio Restoration](https://github.com/Tomasak/GTA-Downgraders/releases/iv-latest) и поверх него распакуйте `opVANILLA.dat`. Передайте папку с получившимся `update` скрипту `tools/build_radio_patch.py` через `--restoration`. Для сборки также нужны `pyrpfiv`, FFmpeg, `IVAudioConv.exe` с его библиотеками из [RAGE Audio Toolkit](https://github.com/AndrewMulti/RAGE-Audio-Toolkit), [ZIP FusionFix](https://github.com/ThirteenAG/GTAIV.EFLC.FusionFix/releases/tag/v5.1.2), установленная GTA IV и два локальных аудиофайла.

```powershell
python -m pip install pyrpfiv
python tools/build_radio_patch.py --restoration "C:\RadioRestoration" --game "C:\Games\GTAIV" --ffmpeg "C:\Tools\ffmpeg.exe" --converter "C:\Tools\IVAudioConv.exe" --fusionfix "C:\Downloads\GTAIV.EFLC.FusionFix.zip" --output LibertyMultiplayer-Radio.zip track1.mp3 track2.mp3
```

## Ручная установка из исходников

1. Нужна Steam-сборка GTA IV `1.2.0.59` и Python 3.10 или новее.
2. Рядом с `GTAIV.exe` установите 32-битный [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) и [ScriptHookDotNet CE 1.7.2.0](https://www.nexusmods.com/gta4/mods/1217?tab=files).
3. Скопируйте `scripts/LibertyFriends.cs` в `GTAIV/scripts/`. Если используете собранный `LibertyFriends.net.dll`, положите туда только DLL. Скопируйте `mods/LibertyFriends` из проекта в `GTAIV/mods/`: эта папка служит для обмена данными с Python. Команды ниже выполняются из папки с `liberty_friends.py`.

## Закрытая сессия

Используйте одну локальную сеть или частную VPN. На хосте сгенерируйте ключ и передайте его участникам приватно.

```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Хост запускает сервер. Замените `IP_ХОСТА` на адрес хоста в общей сети, а `КЛЮЧ` на полученное значение.

```powershell
python liberty_friends.py serve --bind IP_ХОСТА --key КЛЮЧ
```

Каждый участник, включая хост, запускает клиент. Укажите путь к своей установленной папке мода. Если Windows блокирует обмен, проверьте доступ к входящему UDP-порту `24840` на хосте в общей сети.

```powershell
python liberty_friends.py join --host IP_ХОСТА --key КЛЮЧ --mod-dir "C:\ПапкаИгры\GTAIV\mods\LibertyFriends"
```

Запустите основную GTA IV и загрузите свободную игру из сохранения. После подключения через лаунчер синхронизация начнётся, когда сможете управлять персонажем. Откройте карту после того, как оба игрока войдут в мир. Зелёная отметка должна двигаться вслед за другом и исчезнуть через несколько секунд после остановки его клиента. Если отметок нет, убедитесь, что рядом с `manifest.lua` обновляются файлы `position.txt` и `peers.txt`, и посмотрите журнал запуска в client.log.

Протокол проверяет подлинность пакетов общим ключом HMAC. Координаты передаются открытым текстом, поэтому для игры через интернет используйте частную VPN. Для проверки на одном ПК адрес сервера по умолчанию — `127.0.0.1`.
